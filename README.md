# SAYURI BEYOND v0.1.0 — Awakening

Personal AI assistant workspace.

The current foundation uses the **Authdoor shadcn-admin** shell as a clean, editable React/Vite UI base. The shell is being adapted for SAYURI BEYOND before the chat, avatar, memory, agent core and document intelligence layers are added.

## Stack

- React 19
- TypeScript
- Vite
- Tailwind CSS 4
- shadcn/ui
- TanStack Router
- TanStack Query
- Zustand
- i18next
- MSW

## Development

```bash
pnpm install
pnpm dev
```

Production build:

```bash
pnpm build
```

## Current stage

**v0.1.0 Awakening**

Current focus:
- website shell;
- navigation and layout;
- design system;
- chat interface foundation.

Avatar, Live2D, voice, memory and AI-agent features are planned for later stages.
